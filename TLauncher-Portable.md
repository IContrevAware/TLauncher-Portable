TLauncher-Portable   
==================  
I don\'t like TL but lots of  
people do so, portable time  
  
1. create a folder I will name it \"TLP\" for this tutorial.  
2. Download portable java we will use [adoptium j](https://adoptium.net/en-GB/temurin/releases)  
3. NOTE: download JRE zip for windows  
4. Go to TLauncher\'s official website : [tlauncher.org  ](https://tlauncher.org/)  
5. Download it  
6. Extract the Java ZIP so bin is in a subfolder eg: D:\TLP\Java\ (bin at D:\TLP\Java\bin)  
7. Open the Tlauncher installation file  
8. If it says "Do you want this app to make changes to your device" or something similar then accept  
9. Now install it normally (Don't worry, we will make this portable soon)  
10. Uncheck all the boxes.  
11. Press Win+R (the Win button is the button with 4 squares on it on the keyboard)  
12. Type exactly "%appdata%  
13. Go to the .minecraft folder  
14. Copy the Tlauncher.exe  
15. Paste it into the TLP folder (or the folder name)  
16. Go back to the Appdata folder and delete .minecraft and .tlauncher  
17. Open it in a note editing tool (any)  
18. Go to [https://pastebin.com/KUR7GbxJ](https://pastebin.com/zQin6q96) and copy the text and paste it  
19. Then click save as, then name it whatever but make sure it is on All Files and named (Your_Name).bat but I will name it Start.bat and click ok  
20. Delete text document but keep the .bat file  
21. DONE! Always start it from Start.bat
